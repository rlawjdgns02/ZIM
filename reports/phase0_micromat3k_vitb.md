## 3. 분석

### 3.1 재현 성공
- 논문과 비교 가능한 64개 수치(Table 1의 40개 + Table 6의 24개) 모두 **상대 오차 ±0.8% 이내**.
- 남은 차이는 ONNX Runtime 버전 / GPU 연산 차이 수준으로 판단. **평가 파이프라인은 신뢰 가능**하며, 새 데이터셋 실험에 그대로 사용한다.

### 3.2 ZIM > SAM 주장 확인 (MicroMat-3K 한정)
MSE 기준 개선 배율 (SAM ÷ ZIM):

| | point | bbox |
|---|---|---|
| fine | 2.6× (21.69 → 8.23) | 5.8× (11.06 → 1.89) |
| coarse | 3.1× (5.57 → 1.80) | 2.3× (1.05 → 0.45) |

- 전체(all) 기준 비교 20개(프롬프트 2 × 분할 2 × 지표 5) 모두 ZIM 우세 → 논문 주장과 일치.

### 3.3 개선은 대부분 큰 객체(L)에서 나온다
- fine·bbox 기준 크기별 개선 배율: S 1.6× (0.329 → 0.205), M 1.3× (2.98 → 2.22), **L 10.7× (38.59 → 3.62)**.
- 전체(all) 평균에서 L 그룹이 차지하는 비중 (fine·bbox, 샘플 수 × 평균으로 계산):
  - SAM: 189개(25%)가 전체 오차의 **약 88%**
  - ZIM: 189개(25%)가 전체 오차의 약 48%
- 원인: MSE/SAD가 **이미지 전체 픽셀 기준**이라, 전경이 작은 객체는 오차가 커도 평균값이 작게 나온다. 결과적으로 "all" 수치는 큰 객체의 성능이 좌우한다.
- **시사점:** 새 데이터셋에서도 S/M/L을 반드시 나눠 보고하고, 가능하면 전경/박스 영역 기준으로 정규화한 오차도 함께 보고한다.

### 3.4 작은 coarse 객체 + 박스에서는 SAM이 근소하게 우세
- coarse·bbox·S (1,753개, coarse 전체의 78%): MSE **SAM 0.180 vs ZIM 0.198**, SAD 0.820 vs 0.902, MAE 0.289 vs 0.319.
- 논문 Table 6에도 같은 경향(0.181 vs 0.200)이 있으나 본문에서는 언급되지 않음.
- 반면 Grad는 ZIM이 더 낮음(0.922 vs 1.246) → 경계 형태는 ZIM이 낫지만, 전체 픽셀 오차는 이진 출력인 SAM이 약간 유리.
- **시사점:** "coarse 객체에서도 성능이 떨어지지 않는다"(E2)는 주장은 **작은 객체에서는 조건부**. 새 데이터셋(DIS5K TE1 등)에서 집중 검증할 후보.

### 3.5 Grad는 모든 그룹에서 ZIM 우세
- 16개 조합(프롬프트 2 × 분할 2 × 크기 4: all/S/M/L) 전부에서 ZIM의 Grad가 SAM보다 낮음.
- 미세 경계 표현이 좋아졌다는 주장은 MSE보다 Grad에서 더 일관되게 지지된다.

### 3.6 점 프롬프트는 여전히 약점
- ZIM에서도 점 프롬프트가 박스보다 크게 나쁨: fine L 25.05 vs 3.62, coarse L 19.12 vs 0.63 (약 30×).
- 점은 "부분 vs 전체" 중 무엇을 원하는지 애매하다. 논문이 한계로 밝힌 "SAM의 애매한 프롬프트 처리를 그대로 물려받음"과 부합.
- 단, coarse L은 37개뿐이라 수치 변동이 클 수 있음.

## 4. 주의 사항
- SAM 출력은 평가 코드에서 0/1 이진 마스크로 변환된 뒤 연속값 matte와 비교된다(`multimask_output=False`, `return_logits=False`). 연속값을 내는 ZIM에 구조적으로 유리 → Phase 2의 F1(SAM soft 출력)에서 점검 예정.
- MicroMat-3K 정답은 저자들의 라벨 컨버터로 만든 pseudo-label을 사람이 수정한 것이다. 이 결과는 "같은 파이프라인 안에서의 재현"이며, 독립 데이터셋 검증은 Phase 1에서 수행한다.

## 5. 다음 단계에 반영할 것
1. 새 데이터셋 결과도 S/M/L과 그룹별 샘플 수를 함께 보고한다.
2. 이미지 전체 기준 지표 외에 전경/박스 영역 정규화 지표를 추가한다 (3.3).
3. 작은 coarse 객체에서 SAM ≥ ZIM 현상이 다른 데이터에서도 나타나는지 확인한다 (3.4, E2).
4. Grad를 핵심 지표로 함께 강조한다 (3.5).
