# P3M-500-NP 얼굴 블러 실험: 얼굴을 가리면 ZIM / SAM 성능이 어떻게 변하는가 (ViT-B)

- 실행일: 2026-11-22
- 환경: Windows 11, RTX 2070 (8GB), torch 2.4.1+cu124, onnxruntime-gpu 1.20.2 (CUDAExecutionProvider)
- 모델: ZIM `zim_vit_b_2043` (ONNX) vs SAM `sam_vit_b_01ec64.pth`
- 데이터: P3M-10k validation의 **P3M-500-NP** (얼굴이 가려지지 않은 인물 사진 500장, 사람이 라벨링한 alpha matte)
- 이미지별 결과: [P3M500NP_face_blur_per_image.csv](P3M500NP_face_blur_per_image.csv) (원본과 블러 점수를 나란히 저장, 272장 × 2모델 × 2프롬프트)

## 요약

- **얼굴 검출:** YuNet(신뢰도 ≥ 0.9)으로 **500장 중 272장(54.4%)**에서 얼굴을 검출했습니다(얼굴 1개 263장, 2개 이상 9장). 미검출 228장은 직접 확인한 결과 대부분 뒷모습이었습니다.
- **ZIM은 블러에 강합니다. 다만 경계 품질은 조금 나빠집니다.**
  - 박스 MSE 평균은 28.39 → 28.12로 변화가 없었습니다(95% CI [−2.51, +1.62]). 크게 나빠진 이미지와 크게 좋아진 이미지가 섞여 평균에서 상쇄됐습니다.
  - 이미지 단위로 보면 73%가 약간 나빠졌습니다(중앙값 1.05 → 1.75, p = 1.7×10⁻¹⁴).
  - 경계 지표 Grad는 박스·점 모두 **+5~7% 나빠졌습니다**(CI가 0을 포함하지 않음). 이 악화는 블러가 머리카락 등 반투명 경계를 덮은 정도와 상관관계가 있습니다(ρ = +0.39).
- **SAM은 블러에 더 취약합니다.** 박스 MSE 평균이 **+12.2% 나빠졌고**(120.32 → 135.02, CI [+3.89, +26.58]), 실패(MSE>100)가 79장 → 90장으로 늘었습니다. 나빠진 사례를 보면 얼굴이 사라지자 사람 전체 대신 옷 무늬 같은 **다른 영역을 선택하는 실패**였습니다.
- **ZIM > SAM 우위는 블러 후에도 유지됩니다.** 박스 MSE 기준 SAM÷ZIM 비율은 4.24× → 4.80×로 오히려 커졌고, ZIM 승률은 96.0%로 같습니다. 같은 이미지에서 블러로 인한 변화량도 SAM이 더 컸습니다(|ΔZIM| > |ΔSAM|인 이미지 13.6%).

- 임계값을 0.9로 정한 이유: 0.6으로 낮추면 57장을 더 검출하지만, 그중 상당수가 **뒤통수나 머리카락을 얼굴로 잘못 잡은 경우**였습니다. 머리카락을 블러하면 "얼굴 블러" 효과와 "미세 구조 훼손" 효과가 섞이므로, 정밀도를 우선했습니다. 0.9에서 검출된 이미지 중 72장을 직접 확인했고 오검출은 없었습니다.
- 지표 단위: MSE·MAE는 ×10³, SAD·Conn은 ÷1000 (E1 보고서와 같음). 모두 낮을수록 좋습니다.

## 3. 분석

### 3.1 SAM: 얼굴이 "사람 전체"를 고르는 단서였다
- 박스 MSE가 평균 +12%, 실패가 79 → 90장으로 늘었습니다. 새로 실패한 이미지가 17장, 실패에서 벗어난 이미지가 6장입니다.
- 크게 나빠진 사례(p_99a33b12: 29.6 → 722.2, p_347de0d7: 5.3 → 367.1)를 다시 추론해 보니, 블러 후 SAM은 사람 전체 대신 **옷 무늬나 얼굴 블러 영역 같은 일부만 선택**했습니다. 경계가 조금 나빠진 것이 아니라 **선택한 영역 자체가 바뀌었습니다.**
- SAM의 변화는 블러가 반투명 경계를 덮은 정도와 상관이 없습니다(ρ = −0.06). 반면 블러 면적과는 약한 상관이 있습니다(ρ = +0.19). 즉 경계 디테일 손실보다 **"이 박스 안의 주 객체가 무엇인가"라는 판단이 흔들린 것**으로 해석됩니다.

### 3.2 ZIM: 영역 선택은 안정적이고, 경계와 확신도가 약간 떨어진다
- 평균 MSE는 변화가 없지만(CI가 0 포함), 이미지 73%에서 **작지만 일관되게 나빠졌습니다**(중앙값 1.05 → 1.75). 평균이 그대로인 이유는 크게 좋아진 소수의 이미지가 상쇄했기 때문입니다.
  - 예: p_b0481f35는 원본에서 ZIM과 SAM 모두 **얼굴을 빼고 머리카락만** matte로 잡았습니다(MSE 197). 블러 후 ZIM은 얼굴까지 포함해 MSE 1.3이 됐습니다. 얼굴 디테일이 사라지면서 "머리카락 vs 얼굴"을 별개 객체로 나누던 단서가 없어진 것으로 보입니다.
- 나빠진 사례(p_ccb611f0, p_256d45f3)에서 ZIM은 영역은 맞게 잡았습니다. 대신 **몸 전체의 alpha가 1보다 낮게(회색으로) 나왔습니다.** SAM처럼 다른 영역으로 넘어가지는 않았습니다.
- Grad(경계)는 박스·점 모두 확실히 나빠졌습니다(+6.8%, +4.5%). 그리고 블러가 반투명 경계를 많이 덮을수록 ΔMSE가 커집니다(ρ = +0.39, 상위 25% 평균 +2.35 vs 나머지 −1.15).

### 3.3 해석 시 주의: 경계 악화 일부는 "라벨 불일치"다
- 블러는 얼굴에 붙은 **머리카락 경계도 일부 지웁니다**(반투명 픽셀 중앙값 12.6%, p90 33.9%). 그런데 정답 matte는 원본 그대로입니다. 이미지에 더 이상 없는 머리카락 디테일을 맞혀야 하는 셈이므로, ZIM의 Grad 악화 중 일부는 모델 결함이 아니라 이 실험 설계에서 피할 수 없는 손실입니다.
- 반대로 SAM의 악화는 이런 경계 겹침과 무관하므로(3.1절) 이 문제의 영향을 받지 않습니다.

### 3.4 결론
- **ZIM의 우위는 얼굴을 가린 조건에서도 유지되고 오히려 커졌습니다**(박스 SAM÷ZIM 4.24× → 4.80×).
- P3M-500-P처럼 얼굴을 블러해 공개하는 데이터나 프라이버시 처리된 입력에서는 SAM의 프롬프트 기반 분할이 더 불안정해집니다. ZIM은 영역 선택이 안정적이고 경계 품질만 소폭(Grad 5~7%) 떨어집니다.

## 4. 한계

- 얼굴 검출은 정밀도 우선(신뢰도 0.9)이라 옆얼굴, 작은 얼굴, 선글라스 착용 얼굴 일부가 빠졌습니다. 블러 결과는 "정면에 가깝고 잘 보이는 얼굴" 272장에 대한 결과입니다.
- 블러 강도(σ = 얼굴 크기 × 0.125)와 영역 확장(20%)은 한 설정만 실험했습니다. 강도에 따른 변화(용량-반응)는 확인하지 않았습니다.
- 평가 코드가 SAM 출력을 0/1 이진 마스크로 바꾸는 점은 E1/E7과 같은 공통 한계입니다(→ F1).
